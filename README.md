# notes64

These are my notes on Smash 64. You can read them at [notes.12cb.dev](https://notes.12cb.dev).

I took these notes using [Obsidian](https://obsidian.md/) and published them using [Quartz](https://github.com/jackyzha0/quartz).

## Building

Install dependencies:

```sh
$ npm i
```

Build:

```sh
$ npx quartz build
```

Build and serve (locally):

```sh
$ npx quartz build --serve
```
